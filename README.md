# Portafolio de Christian Daniel Campaña Díaz

Portafolio web estático de Christian Daniel Campaña Díaz, Software Engineer enfocado en desarrollo full-stack, inteligencia artificial, cloud y DevOps.

El sitio presenta su experiencia profesional, stack técnico, proyectos destacados, formación académica y canales de contacto en una experiencia editorial responsive.

## Características

- HTML, CSS y JavaScript vanilla, sin frameworks ni proceso de build.
- Diseño oscuro con opción de modo claro.
- Navegación responsive para móvil y escritorio.
- Animaciones ligeras al hacer scroll con `IntersectionObserver`.
- Selector de descarga de CV en español e inglés.
- Secciones de experiencia, habilidades, proyectos, educación y contacto.
- Compatible con despliegue directo en Netlify u otros servicios de hosting estático.

## Estructura

```text
.
├── index.html       # Estructura y contenido del portafolio
├── styles.css       # Sistema visual y estilos responsive
├── scripts.js       # Navegación, tema, CV y animaciones
└── public/
    ├── docs/        # CV en español e inglés
    └── img/         # Recursos visuales
```

## Uso local

Abre `index.html` directamente en el navegador o sirve la carpeta con cualquier servidor estático.

Por ejemplo, con VS Code se puede utilizar la extensión Live Server. No es necesario instalar dependencias ni ejecutar un proceso de compilación.

## Publicación

El proyecto puede desplegarse subiendo la carpeta completa a Netlify o conectando el repositorio a un servicio de hosting estático.

Las métricas y datos de contacto que aún no estén confirmados deben actualizarse antes de publicar una versión definitiva.
